# TVD Vampirism - A Vampirism & Werewolves Addon
This mod aims to enhance TeamLapen's Vampirism/Werewolves mods with new types of vampires, items, skills and features, inspired by The Vampire Diaries.

A quick overview on what this mod adds:
### Augustine Vampires
A cannibalistic type of vampire that feeds on regular vampires. Spooky!
### Hybrids
A powerful beast that is both vampire and werewolf at the same time.
### Original Vampires
First generation vampires that are very (very) hard to kill.
### Original Hybrids
An immortal hybrid cursed with immortality, thus packed with raw power.

---
Every new vampire type has their own special features, mechanics and custom skills. Everything about this mod is documented here, so visit the wiki of this mod before asking them! The chances are really high that you'll find your answer there.
## General Changes and Additions
- Vampires should actually burn in the sun, right? Well, now they do!
- Daylight rings. You know it, that's the good stuff.
- A cure for vampirism instead of a cleansing altar
- Zombies, skeletons and creepers attack vampires by default, since it would be too easy right?
## Important!
Before you think some of these are not to your taste - everything can be configured in the server config file of this mod. The loot chances, individual features and so on.

The whole mod is written with performance in mind, and utilizes many vampirism/werewolves features.

For now, this mod will NOT be ported to any other minecraft version.
